Only the equations for the active mode are shown. The inactive set is meaningless here — equation (5) returns a negative number when VSYS > VBUS, and the two modes define D differently.

Worst case across the range

—

Buck and boost worst cases are computed separately, each from only the operating points in that mode. Points where VBUS = VSYS are skipped — neither equation applies in buck-boost transition.

Each row is the worst case over every combination of the other three ranges at that axis value. Buck rows use the input capacitor (equations 7 and 8); boost rows use the output capacitor (9 and 10). An accent-coloured cell is the column maximum for that mode.

Sweeping VBUS alone will not show the D = 0.5 peak. With VSYS pinned, inductor ripple simply rises with VBUS. The D = 0.5 maximum the datasheet describes appears when VSYS varies at fixed VBUS. Both readings are the same formula — give VSYS a range to see it.

Equations as printed

Eq Mode Formula
4 Either I_SAT ≥ MAX[ (I_IN + I_RIPPLE / 2), (I_CHG + I_RIPPLE / 2) ]
5 Buck I_RIPPLE_BUCK = ( V_SYS × (V_BUS − V_SYS) ) / ( V_BUS × F_SW × L )
6 Boost I_RIPPLE_BOOST = ( V_BUS × (V_SYS − V_BUS) ) / ( V_SYS × F_SW × L )
7 Buck I_CIN_BUCK = I_CHG × √( D × (1 − D) )   where D = V_SYS / V_BUS
8 Buck ΔV_IN_BUCK = ( D × (1 − D) × I_CHG ) / ( C_IN × F_SW )   where D = V_SYS / V_BUS
9 Boost I_COUT_BOOST = I_CHG × √( D / (1 − D) )   where D = 1 − V_BUS / V_SYS
10 Boost ΔV_OUT_BOOST = ( I_CHG × D ) / ( C_OUT × F_SW )   where D = 1 − V_BUS / V_SYS

D is defined differently in the two modes. Buck (7, 8): D = V_SYS / V_BUS. Boost (9, 10): D = 1 − V_BUS / V_SYS. A calculator that computes one duty cycle and reuses it is wrong in one of the two modes.

TI's in-text equation cross-references are off by one. Every prose reference in §10.2.2 points at the equation before the one it means — the text's “equations (4) and (5)” for inductor ripple actually means (5) and (6), and so on through (10). Equation (4) is the inductor saturation requirement, not a ripple formula. The numbering used on this page is the one printed beside each equation.

Ripple voltages (8, 10) assume an ideal capacitor. There is no ESR term, so real ripple is higher. For ceramic X5R/X7R parts the effective capacitance also drops with DC bias and temperature, which raises ripple further.

Worst cases the datasheet calls out

Inductor ripple (5): with VSYS pinned near 8 V, ripple rises with VBUS — worst at 15–20 V. The text's “maximum in the vicinity of D = 0.5” holds for fixed VBUS with varying VSYS; sweeping VBUS instead will not show a peak at D = 0.5. Input capacitor (7, 8): worst at D = 0.5, i.e. VBUS 15–20 V for VSYS ≈ 8 V. At D = 0.5 the RMS current is exactly ICHG / 2. Output capacitor (9, 10): worst at the lowest VBUS, i.e. 5 V. Equation (9) diverges as D → 1.

Not covered by these equations

MPPT / VOC_PCT (§10.2.2.1, §9.3.6.3) is a ratio lookup, not an equation: VMPP / VOC from the panel datasheet, rounded to the nearest available setting. TI's worked example is 8.0 V / 10.0 V = 80% → VOC_PCT = 4 (81.25%). Efficiency, thermal and power-loss equations are not in §10.2.2. Register field encodings for ICHG / IINDPM / VREG / VOTG are in the register map, §9.6. If backup mode is used, add 2×33 µF POSCAP at PMID to hold the rail through adapter removal (§10.2.2.3/4).
