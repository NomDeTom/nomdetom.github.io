meshtasticd Pinout Map

Paste or load meshtasticd config.d YAML and see which Raspberry Pi header pins it uses. Stack a radio and a display to spot clashes between them.

Back to index

Did you know: this tool can be saved and used locally! Only "Load list" needs the network.

Example configs and the pin keys come from meshtastic/firmware bin/config.d (GPL-3.0). BPI-R4 header from the BPI-R4 GPIO define table. ROCK 2F header traced from the Radxa ROCK 2F v1.01 schematic (sheet 23 and the RK3528 sheets). Lyra Ultra, Lyra Zero W and Pico Mini headers from Luckfox's published pinouts (Pico Mini also on the Femtofox wiki); Pico Ultra header positions read from the wehooper4 Luckfox Ultra Hat schematic.
