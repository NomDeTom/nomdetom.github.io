Meshtastic Node ID Tool

Recreates the firmware identity chain in browser: private key to Curve25519 public key, then CRC32(public key) to node number and !nodeId.

Back to home

This tool implements Meshtastic firmware identity behavior (private key to Curve25519 public key to CRC32 node number).

Random private keys are generated locally using your browser/device internal random generator.

Input supports raw hex (with or without 0x) and base64/base64url. All key bytes are interpreted as little-endian where required by X25519.
