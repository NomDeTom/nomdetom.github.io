Code Points to UTF-8

UTF-8 splits a code point across one to four bytes. The leading byte says how many bytes follow, every continuation byte starts 10, and the remaining slots carry the code point's bits from the top down.

Bits the encoding fixes. Payload slots carry code point bits; italic zeros are padding.

Code Points to UTF-16

A code point in the Basic Multilingual Plane is one 16-bit unit holding its own value. Above U+FFFF, 0x10000 is subtracted and the remaining 20 bits are split across a high and a low surrogate.

UTF-8 Bytes to Base64

Base64 regroups the bytes into 24-bit blocks and reads each block as four 6-bit indices into the alphabet A–Z a–z 0–9 + /. A short final block is padded with zero bits to fill the last index, and = stands in for each index the input never reached.
