Equation reference

Quantity Buck Boost
Duty cycle D = VOUT / VIN D = 1 - VIN / VOUT
Average inductor current IL = IOUT IL = IOUT / (1 - D)
Inductor ripple, peak-to-peak ΔIL = (VIN - VOUT) D / (L fSW) ΔIL = VIN D / (L fSW)
Switch RMS current ISW(rms) = sqrt(D (IL² + ΔIL² / 12))
Rectifier RMS current IRECT(rms) = sqrt((1 - D) (IL² + ΔIL² / 12))
Output capacitor RMS current ICOUT(rms) = ΔIL / (2 sqrt(3)) ICOUT(rms)² = IOUT² D / (1 - D) + (1 - D) ΔIL² / 12
Capacitive output ripple ΔV = ΔIL / (8 fSW COUT) ΔV = IOUT D / (fSW COUT)

Assumptions: ideal conversion ratio, steady state, continuous conduction, triangular inductor ripple, constant load current, and negligible switching dead time. RMS convention: switch and rectifier values include the triangular ripple term, not only the common square-root duty approximation.

These are first-pass component stresses, not final ratings. Semiconductor voltage stress, switching overshoot, losses, thermal limits, control-loop stability, core loss, inductor saturation tolerance, capacitor bias derating, and transient margin still need to be checked against the chosen topology and parts. A synchronous MOSFET carries the current shown as rectifier current.
