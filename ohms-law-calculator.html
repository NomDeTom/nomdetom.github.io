Formulas

V = I x R P = I x V Series equivalent resistance: R(eq) = R1 + R2 + R3 + ... Parallel equivalent resistance: 1 / R(eq) = 1/R1 + 1/R2 + 1/R3 + ... Series equivalent capacitance: 1 / C(eq) = 1/C1 + 1/C2 + 1/C3 + ... Parallel equivalent capacitance: C(eq) = C1 + C2 + C3 + ... Series equivalent inductance: L(eq) = L1 + L2 + L3 + ... Parallel equivalent inductance: 1 / L(eq) = 1/L1 + 1/L2 + 1/L3 + ... Inductor formulas assume no mutual coupling between the parts.
